# NAVI Abyss / NAVI Universe
The [cosmic reference experience](../reference.html) consumes a committed Graphify public catalog snapshot. Its renderer projects 3D water, ships and repository stars using native Canvas. The public graph is curated; no live fetch or private graph ingestion. The shared [theme](universe.css) remains compatible with [GitHub Homepage](https://github.com/Neguchads/github-homepage) and the [profile](https://github.com/Neguchads/Neguchads). The separate legacy WebGPU underwater engine remains intact under its original MIT attribution.
